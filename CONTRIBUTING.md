# Contributing

Thank you for helping. ShadowJS is split into one repository per package; a change goes to the repository of the package it changes.

1. Find the package: the table in the [README](README.md) links every repository.
2. Open an issue there first for anything that adds or changes public API, behavior, supported platforms or dependencies.
3. Follow that repository's CONTRIBUTING.md (setup, the commands, and what a good change looks like) and its AGENTS.md (the layout, the rules and how a pull request is reviewed; written for people and coding agents alike).

A change that spans packages starts as an issue here, in Discussions, so the maintainers can decide where it belongs.

Everyone taking part follows [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). By contributing you agree that your contribution is licensed under the
MIT license of the repository you contribute to.
