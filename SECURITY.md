# Security policy

Every package and `create-shadow-app` share one version number. Security fixes are released for the latest minor of the current major version
and for the previous minor for six months after the next minor ships.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting on the repository of the package concerned (its **Security**
tab, then **Report a vulnerability**), or on this repository if you are not sure which package it is. Include the package and version, a
description and its impact, a minimal reproduction, and whether the problem is already public.

You will get an acknowledgment within three working days and a first assessment within ten. We agree on a disclosure date with you
(normally within 90 days of the report) and credit you in the advisory unless you prefer to stay anonymous. Releases are published with npm
provenance.
