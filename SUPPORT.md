# Getting help

- **Questions and how-to:** use GitHub Discussions. Search first, then include a minimal reproduction, your Node.js version, your package
  manager and the output of `npm ls @shadow-js/core @shadow-js/web`.
- **Bugs:** open an issue with the bug report form. A failing test or a small repository is the fastest way to a fix.
- **Feature ideas:** open an issue with the feature request form and describe the problem before the solution.
- **Security problems:** never in public. See SECURITY.md.
- **Documentation problems:** open an issue with the documentation form; link the page.

## What is supported

- Node.js 22.12 and newer (the active and maintenance LTS lines).
- The latest minor of the current major version of every package (see SECURITY.md for security fixes of the previous major).
- TypeScript 5.8 and newer, Vite 8, and evergreen browsers (the latest two versions of Chrome, Edge, Firefox and Safari).
- Package managers: npm, yarn, pnpm and bun.

Commercial support and consulting are not offered by the project.
